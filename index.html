Voucher Wallet

Aide et informations pour l'application qui centralise vos bons d'achat, cartes cadeaux, coupons, codes-barres et PDF dans un portefeuille simple à consulter.

Guide rapide

  1. Ajoutez un bonDepuis l'accueil, importez un PDF ou saisissez les informations du bon manuellement.
  2. Vérifiez les informationsContrôlez l'enseigne, le montant, la date d'expiration, le numéro du bon et le code PIN si nécessaire.
  3. Présentez le codeOuvrez le détail du bon, puis touchez le code-barres ou le QR code pour l'afficher plus confortablement au moment du passage en caisse.
  4. Suivez vos dépensesAjoutez les achats réalisés pour garder un solde restant clair et éviter les mauvaises surprises.

Ce que permet l'app

  • Ajouter des bons d'achat manuellement ou depuis un PDF.
  • Retrouver rapidement un bon par enseigne, montant ou date d'expiration.
  • Afficher un QR code ou un code-barres quand le bon en contient un.
  • Suivre le solde restant et l'historique des dépenses.
  • Personnaliser les couleurs des cartes avec contrôle de lisibilité.

Conseils pour l'import PDF

  • Utilisez de préférence le PDF original reçu par e-mail ou téléchargé depuis l'espace client de l'enseigne.
  • Si le PDF contient plusieurs bons, relisez chaque fiche avant l'enregistrement.
  • Si une information est mal détectée, corrigez-la avant d'ajouter le bon à votre portefeuille.
  • Gardez le document original jusqu'à ce que le bon ait bien été utilisé.

Questions fréquentes

L'import PDF ne trouve pas mon bon.
Vérifiez que le PDF contient du texte lisible ou une image nette. Vous pouvez toujours compléter les champs manuellement.

Mon code-barres ne passe pas en caisse.
Touchez le code dans le détail du bon pour l'afficher en grand, puis vérifiez que le numéro correspond au document original.

Puis-je modifier un bon après l'ajout ?
Oui, ouvrez le détail du bon puis utilisez l'action de modification.

Pourquoi un bon est indiqué comme doublon ?
Voucher Wallet compare les numéros de bons déjà enregistrés pour éviter d'ajouter deux fois le même titre.

Bonnes pratiques

  • Ajoutez la date d'expiration dès que possible pour repérer les bons à utiliser en priorité.
  • Utilisez les favoris pour garder les bons importants en haut de l'accueil.
  • Notez les conditions utiles dans le champ de note : magasin concerné, usage en ligne, minimum d'achat ou restriction.
  • Mettez à jour le solde après chaque achat pour conserver une vue fiable.

Confidentialité

Voucher Wallet est conçu pour fonctionner avec les frameworks natifs d'iOS. Les informations de vos bons d'achat sont enregistrées localement dans l'application. Les PDF importés servent à extraire les informations nécessaires à l'affichage de vos bons.

Pour votre sécurité, ne partagez jamais publiquement une capture contenant un numéro de bon, un code PIN, un QR code ou un code-barres utilisable.
